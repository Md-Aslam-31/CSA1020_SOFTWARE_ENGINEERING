# Experiment 2 — Bus booking

Flow: search (from/to/date/passengers) → compare bus services → select seats → passenger details → review → payment placeholder. Payment is not collected.

Figma handoff: desktop 1440×1000, mobile 390×844; 8 px spacing grid; 44 px touch targets; Auto Layout result cards. Components: labeled fields, primary button, result card, step indicator, available/selected/unavailable seat states, validation message. Prototype links follow the flow.
