# Experiment 01 — CSA1020 Lab Kanban

## Aim
Create a five-card Trello board to track original work for this lab portfolio.

## Tools Required
Trello, a browser, `tasks.csv`, and the original local Kanban simulation in `board/`.

## Algorithm
1. Open the board [SE Lab — Campus Task Board](https://trello.com/b/r3OtgFKJ/se-lab-campus-task-board) created in the authenticated `softlab` workspace.
2. Review the To Do, In Progress, Review, and Done lists.
3. Create the five cards in tasks.csv.
4. Keep requirements and flow mapping Done; leave prototype implementation In Progress and review/release tasks To Do.
5. Record the board URL and capture an account-side screenshot while workspace access is available.

## Local Prototype
[Open the local Kanban board source](board/index.html). It supports drag-and-drop, status menus, search, card editing, priority, owner, and due dates; its state is stored in this browser.

## Output Screenshots
The local simulation is original and available at [board/index.html](board/index.html). The [Trello board link](https://trello.com/b/r3OtgFKJ/se-lab-campus-task-board) is retained. The connector authorization page reported that no Trello workspace was available and that access to the prior workspace had been removed, so current account-side access and a fresh Trello screenshot could not be verified. No friend's screenshot was substituted.

## Result
The local browser simulation supports drag-and-drop, status menus, search, card editing, priority, owner, and due dates; its state is stored in this browser. The existing Trello URL and previously recorded five-card workflow are documented, but live workspace access should be restored before treating the Trello board as currently reviewable.
