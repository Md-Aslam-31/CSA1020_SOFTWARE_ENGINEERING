# Experiment 01 — CSA1020 Lab Kanban

## Aim
Create a five-card Trello board to track original work for this lab portfolio.

## Tools Required
Your Trello account, browser, tasks.csv, and the local Kanban simulation in board/.

## Algorithm
1. Create a board named CSA1020 Lab Work in your Trello workspace.
2. Add To Do, In Progress, and Done lists.
3. Create the five cards in tasks.csv.
4. Keep requirements and flow mapping Done; leave prototype implementation In Progress and review/release tasks To Do.
5. Add the board's own URL and a screenshot after creation.

## Local Prototype
[Open the local Kanban board source](board/index.html). It supports drag-and-drop, status menus, search, card editing, priority, owner, and due dates; its state is stored in this browser.

## Output Screenshots
The local simulation is original. Trello screenshots and the live board link will be added after the Trello connection is active.

## Result
The original five-card workflow and browser simulation are prepared. The live Trello board remains pending connection.
