# Experiment 01 — CSA1020 Lab Kanban

## Aim
Create a five-card Trello board to track original work for this lab portfolio.

## Tools Required
Your Trello account, browser, tasks.csv, and the local Kanban simulation in board/.

## Algorithm
1. Open the board [SE Lab — Campus Task Board](https://trello.com/b/r3OtgFKJ/se-lab-campus-task-board) created in the authenticated `softlab` workspace.
2. Review the To Do, In Progress, Review, and Done lists.
3. Create the five cards in tasks.csv.
4. Keep requirements and flow mapping Done; leave prototype implementation In Progress and review/release tasks To Do.
5. Add the board's own URL and a screenshot after creation.

## Local Prototype
[Open the local Kanban board source](board/index.html). It supports drag-and-drop, status menus, search, card editing, priority, owner, and due dates; its state is stored in this browser.

## Output Screenshots
The local simulation is original. [Open the live Trello board](https://trello.com/b/r3OtgFKJ/se-lab-campus-task-board).

## Result
The original five-card workflow is live in Trello: two cards are in Done, one is In Progress, and two are in To Do. The board includes an empty Review column for the approval step. The browser simulation supports drag-and-drop, status menus, search, card editing, priority, owner, and due dates; its state is stored in this browser.
