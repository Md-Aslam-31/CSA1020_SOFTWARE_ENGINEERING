# Experiment 02 — RouteNest Bus Booking

## Aim
Design a multi-step bus ticket experience and model search, route comparison, seat selection, booking review, ticket management, and feedback.

## Tools Required
Figma and the original local browser prototype in website/.

## Algorithm
1. Search a city pair and travel date; show an animated search state before results.
2. Compare three sample operators, times, vehicle types, availability, and fares.
3. Choose seats up to the passenger count and review the fee breakdown.
4. Save a clearly marked sample trip without sending a reservation or payment.
5. View, edit, or cancel the sample trip, download a text ticket, and save a local trip review.
