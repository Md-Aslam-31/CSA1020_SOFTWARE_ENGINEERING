# Experiment 25 — Fork and pull request

## Aim

Fork public project, make focused branch change and propose upstream PR.

## Tools Required

Git and GitHub.

## Algorithm

Fork/clone; add upstream; branch from upstream main; change/test/commit/push; open PR; respond to review; merge only if maintainer accepts.

## Output Screenshots

Reproducible files and commands are included. External execution is only reported when verified.

## Result

Procedure/proposed change included; no upstream PR fabricated.
