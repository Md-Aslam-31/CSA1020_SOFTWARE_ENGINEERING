# Experiment 09 — GitHub branch, review, and pull request workflow

## Aim
Practice a focused contribution through a feature branch, commits, a reviewed pull request, and merge.

## Tools required
Git, GitHub, and the CampusNotes sample pages in this directory.

| What to open | Link |

## Algorithm

1. Create a focused feature branch from `main`.
2. Implement the weekly planner with responsive layout and accessible feedback.
3. Run the available review checks and inspect the diff for scope and quality.
4. Push the branch, open a PR, review the changes, and merge after checks.

## Result
The `exp09/campusnotes-weekly-planner` feature branch added a searchable weekly planner with task completion, browser-local progress persistence, reset, responsive layout, accessible progress announcements, and reduced-motion support. Pull request #1 was self-reviewed and squash-merged into `main` on 27 October 2026. The self-review checks are recorded in the PR discussion. This is a same-repository feature-branch workflow; the available GitHub connection did not expose a fork-creation action, so this run does not claim a cross-fork contribution or an independent reviewer approval.
