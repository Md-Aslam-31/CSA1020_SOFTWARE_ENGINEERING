# Experiment 09 — GitHub fork and pull request workflow

## Aim
Practice a focused contribution through a fork, feature branch, commits, review, and pull request.

## Tools required
Git, GitHub, and the sample page in this directory.

## Procedure
Fork under your own account; create a feature branch; improve the sample weekly plan; commit and push; open a pull request; review the diff and merge when satisfied.

## Result
This directory contains original practice material. No remote fork or pull request is claimed by this report.
