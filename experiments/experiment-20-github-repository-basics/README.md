## Aim

Plan and document a small personal GitHub repository, initialize it with a useful README, and verify the repository's owner, default branch, files and commit history.

## Algorithm

1. Choose a unique repository name and write a short purpose statement.
2. Prepare a README with purpose, setup steps, usage and contribution guidance.
3. Add a `.gitignore` for editor state, environment files and generated build output.
4. Create the repository under the student's own GitHub account, initialize the default branch and push the first commit.
5. Verify the repository URL, default branch, remote HEAD and visible README.

The report's example is **Lab Journal**, a small repository for recording software-engineering practice. `project/README.md` is a proposed first-file snapshot. The target portfolio repository is the account-owned destination for the experiment collection; the example snapshot is not presented as a second repository created during this run.
