# Experiment 10 — Resolve a Git merge conflict

## Aim
Create a controlled conflict on one shared line, inspect Git markers, reconcile both changes, and complete the merge.

## Tools required
Git and the task-plan sample in this directory.

## Procedure
Commit the baseline on main; create feature/weekly-focus and edit the focus line; return to main and edit the same line differently; merge the feature branch; inspect markers; reconcile both intents, stage, and commit; inspect the graph and resolved file.

## Result
The conflict was created in a disposable Git repository. The conflicting versions and resolution are preserved in evidence/. The merged focus keeps both intents: quiet study blocks and early deadline review. No remote merge is claimed.
