# Experiment 07 — Team Task Requirements: MoSCoW and Kano

## Aim
Prioritize original team-task requirements in Jira using MoSCoW and Kano, with explicit rationale and Kano hypotheses separated from user research.

## Tools Required
Your Jira account and jira-import.csv.

## Algorithm
1. Create a TeamDesk project and enter the 12 requirements from requirements.csv.
2. Set MoSCoW and Kano as separate fields.
3. Record user impact, delivery feasibility, rationale, acceptance evidence, and dependencies for each item.
4. Filter the backlog by both methods and compare the resulting priorities.
5. Keep Kano labels provisional until you collect customer feedback.

## Result
An original 12-row prioritization matrix is ready with impact, feasibility, Kano hypotheses, rationale, and dependencies. It has not yet been entered in your Jira account.
