# Experiment 04 — CampusCart Jira Scrum Sprint

## Aim
Plan a one-week sprint for an original campus marketplace in your Jira account.

## Tools Required
Your Jira account and backlog.csv.

## Algorithm
1. Create a Scrum project named CampusCart.
2. Add eight original backlog stories with estimates, priorities, and acceptance criteria.
3. Select account creation, search, listing details, and create listing for the one-week MVP sprint.
4. Capture the live sprint start board.
5. Update only work actually completed and capture the actual sprint result.
6. Add your project and board URLs here after your Atlassian connection is available.

## Output Screenshots
Jira screenshots are pending project creation in your account. The local backlog is not a live Jira board.

## Result
The original sprint backlog is ready. Jira project creation and status transitions remain pending access.
