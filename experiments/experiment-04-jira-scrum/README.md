# Experiment 04 — CampusCart Jira Scrum Sprint

## Aim
Plan a one-week sprint for an original campus marketplace in your Jira account.

## Tools Required
Your Jira account, jira-import.csv, and sprint-plan.md.

## Algorithm
1. Create a Scrum project named CampusCart.
2. Add eight original stories with estimates, priorities, acceptance criteria, dependencies, and proposed sprint.
3. Select the four foundational Sprint 1 stories for the one-week MVP sprint and review team capacity before starting it.
4. Capture the live sprint start board.
5. Update only work actually completed and capture the actual sprint result.
6. Add your project and board URLs here after your Atlassian connection is available.

## Output Screenshots
Jira screenshots are pending project creation in your account. The local import data and [sprint plan](sprint-plan.md) are planning artifacts, not a live Jira board.

## Result
The original sprint backlog is ready. Jira project creation and status transitions remain pending access.
