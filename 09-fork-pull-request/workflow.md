# Experiment 9 — Fork and pull request

1. Fork an eligible public repository on GitHub.
2. Clone: git clone https://github.com/<your-user>/<repo>.git
3. Add upstream remote for original repository.
4. Create branch: git switch -c docs/improve-setup
5. Make a scoped README update; inspect git diff.
6. git add README.md; git commit -m "docs: clarify setup"
7. git push -u origin docs/improve-setup
8. Open PR to original default branch; summarize problem, change, verification.
9. Address review feedback in another commit and push; merge after required approval/checks.

PR summary template: clarify setup instructions; state change and verification; paste actual PR URL: <URL>. No fork or PR is claimed because no repository or authenticated remote was provided.
